# Мой центр — «Скажи — я разложу»

**Приложение:** https://tsoy7705.github.io/moy-centr/ — на iPhone откройте в Safari → «Поделиться» → «На экран «Домой»».

Персональный планировщик с голосовым вводом по [prd.md](prd.md).

## Файлы

- `app.html` — само приложение (один файл). Публикуется как Artifact на claude.ai:
  личное хранилище (`db`, данные видит только владелец, синхронизация телефон ↔ компьютер),
  разбор фразы через Claude (`sample`), копия данных в `localStorage` для работы без сети.
- `index.html` — та же страница, обёрнутая для самостоятельного хостинга/PWA. Собирается командой `./build.sh`, руками не править.
- `manifest.webmanifest`, `sw.js`, `icon.svg` — PWA: иконка на экране телефона, работа без сети.

## Где работает что

| | Artifact на claude.ai | Свой хостинг (PWA) |
|---|---|---|
| Хранение | личное хранилище аккаунта + копия на устройстве | только на устройстве |
| Разбор фразы | Claude, запасной — правила | правила |
| Кнопка «Сказать» | диктовка через микрофон клавиатуры | запись прямо с кнопки (Chrome/Safari) |

Разборщик на правилах (`Parser` в `app.html`) проходит сценарии приёмки 1–4 из PRD; сценарии 5–7 (висяки, «Готово» → «Вернуть») проверены в браузере.
